# EXAMEN PRUEBA

## Ejercicio 1
1. Crea un documento html que tenga dos input de tipo texto(para el nombre y apellido) y un boton.
2. Al pulsar el botón muestre por consola mediante un alert la frase: "¡Buenos dias Nombre Apellido!"

## Ejercicio 2
1. Crea un div de 100x100px de color verde y debajo 3 botones.
2. Uno de color rojo, amarillo y verde los botones(El texto con su respectivo color del boton).
3. Cuando pulsemos el botón rojo el div se pondra rojo, cuando pulsemos el amarillo el div se pondra amarillo y si es verde se cambia a amarillo.

## Ejercicio 3
- Crea 3 input de tipo numero para las notas de 1º
- Un boton que permetira calcular la media y mostrarla en un div

## Ejercicio 4
- Crea la logica necesaria para que una de las notas es inferior a 5 el resultado de la nota sea un 4 y un texto que indique: "Hay que aprobar los 3 trimestres".
